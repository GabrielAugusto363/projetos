# Problemas e soluções

Esta página reúne os principais problemas que podem ocorrer ao utilizar o site e como resolvê-los.

## 1. A página não carrega
Se a página ficar em branco, demorar muito para abrir ou mostrar erro, verifique:

- se o navegador está atualizado;
- se o site está acessível em outros navegadores;
- se há problema de conexão com a internet;
- se o cache do navegador está causando conflito;
- se o servidor está em execução.

Se o problema persistir, limpe o cache do navegador e recarregue a página.

---

## 2. O arquivo não faz upload
Quando o upload não funciona, normalmente o problema está em um destes pontos:

- o arquivo não está no formato correto;
- o nome do arquivo contém caracteres especiais;
- o arquivo está muito grande;
- o navegador bloqueou a seleção do arquivo;
- a pasta de upload não tem permissão de escrita.

Verifique se o arquivo é um PDF válido, tente outro navegador e confirme se o tamanho do arquivo está dentro do limite permitido.

---

## 3. O botão de processamento não responde
Se o botão não funciona, pode ser por:

- problema de JavaScript no navegador;
- página carregada incompleta;
- conflito de extensão do navegador;
- erro no processamento do arquivo;
- erro no backend da aplicação.

Tente recarregar a página, desativar extensões do navegador e repetir a operação com um arquivo menor.

---

## 4. O download não inicia
Se o arquivo não é baixado após o processamento, verifique:

- se a operação terminou corretamente;
- se o navegador bloqueou janelas pop-up;
- se o arquivo foi gerado na pasta correta;
- se houve erro durante a criação do documento;
- se o navegador está impedindo downloads automáticos.

Em alguns casos, o navegador solicita confirmação antes de baixar o arquivo. Verifique também se o download foi bloqueado por proteção de segurança.

---

## 5. O arquivo gerado está incompleto ou em branco
Se o arquivo gerado estiver vazio, corrompido ou sem páginas, pode ser porque:

- o PDF de entrada foi inválido;
- o documento estava protegido por senha;
- houve falha durante a leitura do arquivo;
- o processamento foi interrompido;
- o arquivo original estava danificado.

Teste o PDF original em outro visualizador para confirmar se ele está funcionando corretamente antes de tentar novamente.

---

## 6. O site fica lento
Se o sistema demorar muito para responder, pode ser causado por:

- arquivo grande;
- muitos arquivos na fila de processamento;
- servidor com pouco recurso;
- processamento pesado de PDFs;
- conflito com outros usuários simultâneos.

Teste com arquivos menores, espere a operação terminar e, se necessário, tente em um horário de menor carga no sistema.

---

## 7. A parte do site não funciona corretamente
Algumas áreas do site podem apresentar falhas visuais ou de interação, como:

- menu não abre;
- botões não clicam;
- campos não respondem;
- páginas podem aparecer travadas.

Isso pode ocorrer por:

- cache do navegador;
- extensão bloqueando scripts;
- falha de carregamento do JavaScript;
- problema no front-end da aplicação.

Atualize a página, limpe o cache e tente novamente. Caso o problema continue, teste em outro navegador.

---

## 8. O site mostra erro no navegador
Se aparecer mensagem como “erro da página”, “falha ao carregar”, ou “recurso indisponível”, verifique:

- conexão com a internet;
- JavaScript habilitado;
- cookies e armazenamento local do navegador;
- bloqueadores de anúncio ou privacidade;
- problemas no servidor do site.

Se o erro for recorrente, tente abrir o site em uma janela anônima ou em outro navegador.

---

## 9. Os arquivos não são salvos corretamente
Se o site não salva o arquivo final ou o download for interrompido, verifique:

- se o navegador está com espaço em disco disponível;
- se a pasta de destino está acessível;
- se o sistema está bloqueando downloads;
- se a operação foi concluída sem erro.

Também é importante verificar se o arquivo original foi processado sem falhas e se há permissões para gravar arquivos temporários.

---

## 10. A ferramenta de conversão ou compressão falha
Se a conversão, compressão ou divisão do PDF falhar, geralmente é por:

- arquivo com estrutura inválida;
- documento muito grande;
- arquivo protegido por senha;
- problema na biblioteca de processamento;
- falha no servidor durante a execução.

Teste com outro PDF, verifique se o arquivo abre corretamente e tente repetir a operação depois de recarregar a página.

---

## 11. Problemas de permissão
Se o site indicar que não foi possível acessar ou salvar arquivos, pode ser problema de permissão do sistema.

Verifique:
- se a pasta de upload existe;
- se há direito de leitura e escrita;
- se o servidor está com as permissões corretas;
- se o arquivo não está travado por outro programa.

---

## 12. Se o problema persistir
Se você já testou as soluções acima e o erro continua, reúna as seguintes informações antes de solicitar ajuda:

- descrição detalhada do problema;
- navegador utilizado;
- sistema operacional;
- mensagem de erro exibida;
- passo a passo para reproduzir o problema;
- arquivo PDF usado, quando possível;
- horário em que o erro ocorreu.

Com essas informações, a análise do problema fica muito mais rápida e precisa.
