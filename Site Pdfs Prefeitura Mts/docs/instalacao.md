# Instalação

## Requisitos

Antes de instalar o sistema, tenha instalado:

- Python 3;
- Git, caso o projeto seja baixado por repositório;
- Acesso à rede interna, quando necessário;
- Permissão para instalar dependências e executar o servidor.

Não é necessário instalar Ghostscript, LibreOffice ou outros programas externos.

## Baixar o projeto

Baixe ou copie a pasta do projeto para o computador ou servidor. Depois, abra o terminal dentro da pasta `pdfPorQpdf`.
